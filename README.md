# Pi Skills

A curated list of agent skills that can be installed for [Pi](https://github.com/badlogic/pi-mono) and other compatible coding agents.

## Skills

1. **gh-axi**

   ```bash
   npx skills add https://github.com/kunchenguid/gh-axi --skill gh-axi
   ```

2. **lavish-axi**

   ```bash
   npx skills add https://github.com/kunchenguid/lavish-axi --skill lavish-axi
   ```

3. **find-skills**

   ```bash

   ```

4. **frontend-design**
